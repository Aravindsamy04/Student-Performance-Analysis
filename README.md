# Student-Performance-Analysis

## Overview:

 🔹 Used Python & Pandas for data loading, cleaning, and basic analysis
 🔹 Built an interactive Power BI dashboard
 🔹 Created KPIs for Total Students, Average Marks, and Average Attendance
 🔹 Analyzed subject-wise and department-wise performance
 🔹 Visualized the relationship between attendance and average marks
 🔹 Added slicers to make the dashboard interactive
 🔹 Used charts to understand the overall performance distribution

 ## Tools and Technologies:

 Python | Pandas | Power BI | Excel/CSV | Data Visualization| VS code
